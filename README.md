Clinic Appointment Tracker - Midterm Project

A console-based Dart OOP application simulating a clinic scheduling system.

Features:
OOP Core: Implements `Appointment` base class with `GeneralCheckup` and `SpecialistConsultation` subclasses.

Abstract Class: `Schedulable` with abstract method `getDetails()`.

Mixin: `LoggerMixin` for timestamped console logging.

Async/Await: Simulates network delays using `Future.delayed()`.

Error Handling: Wrapped in `try-catch` blocks for input validation.
